# Skin & Laser blog posts

Each guide on https://skinandlaser.ae/blog/ is one JSON file in `content/posts/`.

How publishing works:
1. A new file is added here (by the automatic writer or by hand).
2. The website checks this repository about once an hour and copies new or changed posts.
3. A post goes live on its `published` date (Dubai time). A future date schedules it.

This repository must stay **public** so the website can read it. It contains only published articles, no passwords.
Set the repository name once in skinandlaser.ae/admin → Automatic articles.
